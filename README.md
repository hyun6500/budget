# 주현 가계부 앱

가계부 구글시트를 그대로 DB로 쓰는 정적 웹앱입니다. 오운완, 시네마테크, 카드 앱과 같은 구조입니다.

```
구글시트 (입력, 분류표)  <->  Apps Script 웹앱  <->  GitHub Pages 정적 앱
```

배포 주소는 `hyun6500.github.io/ledger/` 를 염두에 두고 만들었습니다.

---

## 1. 시트 올리기

`가계부_마스터.xlsx` 를 구글 드라이브에 올린 뒤 구글 스프레드시트로 변환합니다.
앱이 쓰는 시트는 두 장뿐입니다.

| 시트 | 쓰임 |
|---|---|
| 입력 | 기록 원장. 앱이 읽고 씁니다 |
| 분류표 | 소분류, 상황, 결제수단, 누구 몫, 대접, 테마 목록 |

나머지(월간요약, 연간요약, 월별추이, 원본보관, 검수)는 앱이 건드리지 않습니다. 그대로 두세요.

## 2. Apps Script 붙이기

1. 시트에서 [확장 프로그램 > Apps Script]
2. `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장
3. 왼쪽 톱니 [프로젝트 설정 > 스크립트 속성]에 두 개를 넣습니다

| 이름 | 값 |
|---|---|
| PASSWORD | 편집할 때 넣을 비밀번호 |
| GEMINI_KEY | 화면과 글을 읽어 줄 키. 없으면 읽기 기능만 꺼집니다 |

4. [배포 > 새 배포 > 웹 앱]
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
5. 나온 주소를 복사합니다. `/exec` 로 끝나야 합니다

**Code.gs 를 고칠 때마다 [배포 > 배포 관리 > 연필 > 새 버전]으로 다시 배포하세요.**
새 배포를 만들면 주소가 바뀝니다. 반드시 기존 배포를 수정해야 합니다.
앱 화면 맨 아래에 "서버 불일치" 가 뜨면 이 재배포를 빠뜨린 것입니다.

## 3. 앱 올리기

`js/config.js` 를 열어 두 줄을 채웁니다.

```js
SHEET_ID: "시트 주소의 /d/ 와 /edit 사이 문자열",
APPS_SCRIPT_URL: "위에서 복사한 /exec 주소",
```

그다음 `ledger` 폴더를 통째로 `hyun6500.github.io` 저장소에 올립니다.

**주의**
- `css` 와 `js` 폴더를 빠뜨리기 쉽습니다. 폴더째 끌어다 올리세요
- 주소창에서 복사한 Apps Script 주소는 뒤가 잘려 있습니다. 반드시 [배포 관리]의 복사 아이콘을 쓰세요
- 화면 파일만 고쳤는데 안 바뀌면 `index.html` 의 `?v=1` 을 `?v=2` 로 올리세요

## 화면

| 탭 | 무엇을 |
|---|---|
| 이번 달 | 빠진 고정 지출 알림, 지출 총액, 지난달과 작년 같은 달과 올해 평균 견줌, 대분류 도넛, 날마다 달력, 큰 지출 |
| 추이 | 최근 열두 달 또는 연도별. 달마다 막대와 수입 선, 대분류 흐름, 소분류 순위, 자주 간 곳 |
| 장부 | 옛 월별 탭 그대로. 날짜는 그날 첫 줄에만, 오른쪽에 이 달 통계. 줄을 누르면 고칩니다 |
| 테마 | 여행, 부모님, 용돈, 연인, 소개팅, 동생, 일시성. 누구와 함께였는지도 함께 봅니다 |
| 입력 | 화면이나 글을 읽어 채우기, 직접 적기 |

맨 위의 `26-08` 같은 탭 줄이 달을 고르는 곳입니다. 옛 스프레드시트 탭 이름을 그대로 씁니다.
탭 아래 가는 막대는 그 달에 얼마나 썼는지입니다.

### 금액을 두 겹으로 그립니다

이 앱의 모든 막대는 두 겹입니다. **채운 부분이 내 몫, 빗금이 전액**입니다.
동생과 반씩 나눈 살림이나 가족 여행처럼 남과 나눠 낸 것을 한눈에 알아보게 하려는 것입니다.
숫자도 마찬가지로 내 몫이 크게, 전액이 작게 붙습니다.

### 소개팅과 연인은 어떻게 적나

업종 칸은 그대로 두고 세 칸만 채우면 됩니다.

| | 테마 | 대접 | 동행 |
|---|---|---|---|
| 소개팅 | 소개팅 | 비움 | 상대 이름 |
| 연애 중 | 데이트 | 연인 | 상대 이름 |
| 둘이 반씩 낸 여행 | 데이트 | 연인 | 상대 이름 (누구 몫은 연인과 반반) |

밥값은 식비, 카페는 카페, 영화는 영화로 두세요. **테마와 동행이 그 위를 가로지릅니다.**
그래야 "소개팅에 얼마 썼나"와 "카페에 얼마 썼나"를 둘 다 셀 수 있습니다.

이름은 [소개팅 이력]과 [연애 이력] 시트의 동행 이름 칸과 똑같이 적어야 합니다.
재회처럼 같은 사람을 다시 만난 경우도 동행에는 같은 이름을 쓰고,
이력 시트의 집계 기간으로 나눕니다.

### 빠진 고정 지출 알림

지난 석 달 내리 같은 곳에서 나간 것이 이번 달에 아직 없고,
늘 나가던 날에서 사흘이 지났으면 이번 달 맨 위에 알립니다.
누르면 그 내용이 채워진 채로 입력 탭이 열립니다.

### 화면과 글로 넣기

카드사나 토스 알림 화면을 최대 넉 장까지 올리거나, 문자를 붙여 넣고 [읽어 오기]를 누릅니다.
날짜, 금액, 가맹점, 결제수단, 소분류를 뽑아 후보로 보여 주고, 고르면 아래 칸이 채워집니다.
**채워진 뒤에도 별표가 붙은 칸은 직접 확인하세요.** 기계가 읽은 것은 늘 틀릴 수 있습니다.

읽기는 Gemini 무료 등급을 씁니다. 한도는 API 키가 아니라 구글 클라우드 프로젝트 단위입니다.
시네마테크의 티켓 판독, 카드 앱의 공고 분석과 같은 키를 쓰면 한도를 나눠 씁니다.
한도를 다 쓰면 태평양 자정, 한국 시각으로 오후 네다섯 시에 풀립니다.

## no 를 날짜순으로 다시 매기지 않는 이유

날짜 순서대로 보이는 것과 `no` 를 다시 매기는 것은 다른 일입니다.

- **순서**: 새 줄은 날짜에 맞는 자리에 끼워 넣습니다. 시트는 늘 날짜순으로 보입니다
- **번호**: `no` 는 한 번 받으면 바뀌지 않습니다

`no` 를 다시 매기면 **원본보관 시트와의 연결이 끊어집니다.** 검수할 때 원본을 찾아본 그 번호입니다.
9천 줄을 매번 다시 쓰는 것도 시트에 부담이 큽니다.
정렬이 흐트러졌다면 시트 상단 메뉴 [가계부 앱 > 날짜순으로 정렬]을 한 번 누르세요. `no` 는 그대로 둡니다.

## 시트에서 직접 고쳤을 때

앱이 쓰는 줄은 대분류, 구분, 부담률, 내 몫, 연, 연월을 **값으로** 넣습니다. 수식이 아닙니다.
시트에서 소분류나 누구 몫을 손으로 바꿨다면 [가계부 앱 > 파생 칸 다시 계산]을 눌러 주세요.
전체 줄을 분류표 기준으로 다시 채웁니다. 요약 시트들은 SUMIFS 라서 알아서 따라옵니다.

## 잘 안 될 때

1. 화면 맨 아래 도장을 먼저 보세요. `v1.0 (9/9)` 이 정상입니다
2. "구버전 파일이 섞였습니다" 면 js 폴더 일부만 올라간 것입니다
3. "서버 불일치" 면 Code.gs 재배포를 빠뜨린 것입니다
4. 아무것도 안 뜨면 개발자 도구 콘솔을 열고 `js/core.js` 가 404 인지 확인하세요
5. 시트에 닿지 못한다면 `{Apps Script 주소}?action=ping` 을 브라우저에 넣어 보세요
